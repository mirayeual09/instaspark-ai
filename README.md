# InstaSpark AI

Build a clean, modern frontend for an AI Marketing Agent for Instagram Marketing.
- Aesthetics: Light/white minimalist theme with soft purple/indigo accents, clean cards, subtle borders, and smooth shadows.
- Navigation: Floating pill navbar at the top (capsule / pill-shaped with rounded-full styling, soft shadow, subtle active indicator) with exactly 4 menu items:
  1. AI Agent (default route `/`): Main AI control center featuring prompt/command box for marketing tasks, quick prompt starters (Reels script, Carousel idea, Caption & Hashtags, Bio hook), workflow status, and output preview card.
  2. News (`/news`): Layout displaying trending marketing topics, industry news, and AI-suggested content hooks.
  3. Content Planner (`/planner`): Editorial calendar / schedule view with content status badges (Draft, Scheduled, Published).
  4. Analytics (`/analytics`): Connected Instagram profile card (@handle), growth KPIs, and recent post performance breakdown.
- Client-side routing with clean, modular structure. Frontend and mock data only (no backend/database setup).
